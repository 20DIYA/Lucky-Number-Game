# 🎰 Lucky Number Game (Go CLI Game)

**Lucky Number Game** is a fun and simple command-line game written in Go. The program challenges you to guess a number and then tries multiple times to generate it randomly. If it matches — you win! 🎉

The greater the number you choose, the harder it gets... ready to test your luck? 🍀

---

## 🚀 How to Play

Run the game from the command line and pass in a positive number as your guess:

```bash
go run main.go 7
